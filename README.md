Today’s  travelers  often  face  difficulties  using  multiple  apps  and  websites  to  discover  places, 
plan  itineraries,  and  manage  trip  details.  This  project  aims  to  solve  that  problem  by 
developing  Travista  ,  a  user-friendly  Android  application  that  brings  all  travel-related  features 
into  one  place.  The  main  goal  was  to  create  a  modern,  easy-to-use,  and  reliable  mobile  app 
using the latest Android tools and technologies. 
The  app  is  developed  using  Kotlin  and  Jetpack  Compose  with  a  clean 
Model-View-ViewModel  (MVVM)  architecture.  It  includes  features  like  user  login,  cloud 
data  storage  using  Firebase  ,  and  offline  access  through  Room  database  .  The  app  has  four 
main  sections:  Home  ,  Explore  ,  Trip  Planner  ,  and  Profile  ,  each  designed  to  offer  a  smooth 
and helpful experience to users. 
 




## Tech Stack

### Core

- 100% [Kotlin](https://kotlinlang.org/)
- 100% [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Material3 design](https://m3.material.io/) (UI components)
- [Kotlin Coroutines](https://kotlinlang.org/docs/coroutines-overview.html) (structured concurrency)
- [Kotlin Flow](https://kotlinlang.org/docs/flow.html) (reactive data stream)
- [Hilt](https://dagger.dev/hilt/) (DI)
